# HeetKit v1.2.0

HeetKit 1.2.0 gives you more control over chat commands and who can request AI
replies, with a tidier editor and easier navigation through larger settings.

## What's New

- **Burst messages:** `!tg` and custom commands can send the same message 1–10 times
  in one managed batch. Choose Single, Random or Burst for custom commands, set a
  default repeat count, and optionally let the command argument override it.
- **Burst spacing:** set a separate interval of **0–1000 ms** for `!tg` and each
  custom Burst command. Zero starts all requests together; other values stagger
  their starts without waiting for earlier Twitch responses.
- **Built-in command management:** edit supported settings, permissions, cooldowns,
  responses and safe aliases. Remove commands from your active collection and
  restore individual factory commands or all factory defaults when needed.
- **Blocked AI users:** block or unblock Twitch accounts from the AI page. Changes
  take effect immediately within the selected profile. Blocked `!ask` requests,
  including aliases, are silently ignored before Gemini, conversation memory or
  cooldown processing. Other commands and the local AI Playground still work.

## Improvements

- Commands use clearer mode-specific controls, common template-variable help and
  an optional Advanced variables section. Save applies and persists changes;
  application-styled confirmations protect destructive actions and unsaved edits.
- Built-in editors have compact responsive fields and a right-aligned footer with
  **Remove, Close, Reset and Save**. Response editing retains its own Reset/Save.
- Large AI and Settings sections start collapsed and expand through accessible
  headers. Sidebar links and Dashboard shortcuts open the relevant section before
  scrolling, including the new Blocked AI users shortcut. Collapsing retains drafts.

## Fixes

- Burst delivery starts requests independently instead of waiting for each previous
  response. Individual send failures are collected, and cancellation cleans up the
  whole batch.
- Removing a built-in command preserves its original implementation for restoration.
  Protected permissions and command-name/alias collision checks remain enforced.
- Command editor buttons and confirmation dialogs fit narrow windows more cleanly.

## Upgrading

Quit HeetKit fully through **tray Exit** before running the Windows installer.
Existing profiles, credentials, command settings and templates are retained.
Previously saved custom commands keep their Single or Random behavior; none becomes
Burst automatically. New Burst intervals default to zero. Burst requires at least
Moderator permission, and ordinary Single/Random output limiting is unchanged.

## Known limitations

- Twitch still controls rate limits, message rejection and visible delivery. Burst
  intervals control when requests begin, not when messages appear; delivery and order
  are not guaranteed.
- AI blocks use verified Twitch account IDs when available, with username fallback
  until an account can be verified. A verified ID remains authoritative after a rename.
- Windows 10/11 x64 remains the supported distribution target. Builds are unsigned;
  the existing .NET Framework and WebView2 requirements still apply.
