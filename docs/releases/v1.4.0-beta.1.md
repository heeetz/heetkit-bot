# HeetKit v1.4.0-beta.1

This pre-release adds a headless Linux/Docker runtime and private browser management,
with server setup, operation modes, and portable configuration transfer. It is a
**pre-release for testing**; additional testing and cosmetic refinements are still
planned before the final v1.4.0.

## What's New

- **HeetKit Server:** Run the shared bot backend on Linux/Docker without a desktop
  window. Persistent profiles and container restart support keep server state separate
  from the Windows application. AMD64 is the default, with opt-in ARM64 builds.
- **Private Browser Management:** Manage the bot, commands, AI settings, filters,
  and configuration through the same interface in a browser. Authenticated access
  supports local loopback, SSH tunnels, and explicitly configured private HTTPS.
- **Server Setup & Twitch OAuth:** Configure a fresh server and authorize Twitch
  through browser Settings, without a Desktop installation or copied credentials.
  Local callbacks use the management port; private HTTPS supports remote callbacks.
- **Operation Modes:** Choose Always On, Stream Only, Manual, or Disabled on Server.
  The selected policy persists across restarts; Manual starts stopped, while Stream
  Only follows confirmed broadcaster live/offline status.
- **Configuration Transfer:** Export applied commands, personalities, AI preferences,
  filters, and message triggers between Desktop and Server. Preview and confirm
  imports before replacing configuration; credentials and conversation history are
  excluded.

## Improvements & Fixes

- Simplified primary and fallback model selection, with a separate advanced custom
  model option and consistent keyboard-accessible dropdowns across the interface.
- Fixed command editor focus and scrolling, with more stable dropdown widths and
  clearer controls in smaller windows.
- Prevented duplicate `!tg` bursts and added configurable repeat limits and defaults.
- Improved local browser compatibility, including unrelated localhost cookies in
  Firefox and configurable loopback addresses for Docker management.
- Fixed Server Twitch authorization routing and authenticated account lookup after
  the callback, with clearer private diagnostics when setup fails.
- Added Linux container, private management, backup, and recovery guides, with
  expanded automated coverage for server setup, operation modes, and configuration
  transfer. Remote deployment and native ARM64 acceptance remain to be verified.

## Updating

Exit HeetKit completely through **tray Exit** before running the Windows installer.
Existing profiles, credentials, and settings are preserved. Back up your profile
before testing this beta. Windows 10/11 x64 installer and portable downloads remain
unsigned and require the existing .NET Framework and WebView2 runtimes.

Server runs from source using the [Docker guide](https://github.com/heeetz/heetkit-bot/blob/v1.4.0-beta.1/docs/docker.md).
Set up its private storage, management access, and Twitch authorization separately.
Configuration transfer excludes secrets, OAuth tokens, history, privacy opt-outs,
and the destination's operation mode. Review the import preview and avoid running
Desktop and Server with the same bot account at the same time.

This beta is for testing while further validation and UI polish continue. Existing
redistribution questions are recorded in
[Third-Party Notices](https://github.com/heeetz/heetkit-bot/blob/v1.4.0-beta.1/THIRD_PARTY_NOTICES.md#next-windows-build-corrected-materials-and-remaining-blockers).
