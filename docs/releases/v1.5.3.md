# HeetKit v1.5.3

This release adds command delivery controls, an editor for chat reactions,
and interactive Analytics chart values on Desktop and Server.

## Improvements and fixes

- **Commands:** Choose Chat message, Mention sender, or Reply to message for
  custom Single and Random commands and supported built-ins, including `!ask`
  and `!weather`. Native replies use the invoking message's Twitch thread.
  Existing commands keep their previous delivery until you change the setting.
- **Chat reactions:** Create, edit, remove, and reorder existing rules from
  **Commands > Chat reactions**. The editor header shows the rule's position
  and explains how priority works. Saves take effect immediately.
- **Analytics:** Hover or tap across a chart to see the selected metric and its
  UTC date or hour. Recorded zeros and unavailable values display separately.
- **Weather:** City lookup handles competing matches more reliably. Forecasts
  use the active chat filters, and the global cooldown starts after confirmed
  delivery.
- **Guides:** Setup, command configuration, and recovery instructions are
  organized around common user tasks.

## Updating

Back up the profile and exit Desktop through **tray Exit** before upgrading.
This release adds optional command delivery settings and uses the existing
reaction file and database schemas. Keep the current profile and credentials.
For Server, use the
[release update procedure](https://github.com/heeetz/heetkit-bot/blob/v1.5.3/docs/docker.md#repeatable-release-update)
with the existing volume, secrets, and operating policy.

Windows downloads are unsigned and retain the existing .NET Framework and
WebView2 requirements. See the
[Windows redistribution notes](https://github.com/heeetz/heetkit-bot/blob/v1.5.3/THIRD_PARTY_NOTICES.md#next-windows-build-corrected-materials-and-remaining-blockers).
