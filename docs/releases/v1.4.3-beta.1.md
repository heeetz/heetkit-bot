# HeetKit v1.4.3-beta.1

This pre-release builds on v1.4.2 and adds scheduled Twitch announcements with
highlighted and regular delivery options. It is a **pre-release for testing**.

## What's New

- **Scheduled announcements:** Create interval-based schedules with activity and
  stream availability conditions. Choose a highlighted Twitch announcement in the
  channel's accent color or a regular chat message. New schedules default to
  highlighted; existing schedules retain regular delivery.
- **Announcement management:** Edit saved schedules, immediately enable or disable
  them, and delete them with confirmation. The editor shows Save and Cancel only
  while creating or editing.
- **Highlighted message authorization:** New Twitch authorization requests include
  the permission needed for highlighted announcements. Desktop can renew consent
  while connected; Server can reconnect through Settings. The sending account must
  also be a moderator or broadcaster in the target channel.

## Improvements & Fixes

- Highlighted delivery shares the existing chat output limit and connection lifecycle.
  Failed highlighted sends remain visible and never change to regular messages.
- Existing announcement profiles and portable archives retain regular delivery.
- Refined announcement layout, status spacing, saved-row actions and narrow-screen
  field order across Desktop and Server.

## Updating

This testing pre-release is not offered by the stable update checker. Back up the
existing profile before replacing the application. Existing announcement schedules
continue as regular messages until their type is changed in Commands → Announcements.
Highlighted sending may require renewing Twitch authorization and a moderator or
broadcaster role in the target channel.
