# HeetKit v1.5.2

This release improves Analytics, multilingual weather lookup and Twitch connection
recovery on Desktop and Server.

## Improvements & Fixes

- **Analytics:** The command breakdown includes the full current command inventory,
  including commands with no recorded attempts in the selected range. Rows sort by
  attempts, with historical unavailable commands identified separately. Collection,
  coverage and data management share a clearer layout with expandable details and
  visible warnings about gaps or possible data loss.
- **Weather:** City lookup compares exact matches across Ukrainian, Russian and
  English results, preserves country constraints and asks for clarification when
  several places match. Results identify the region and country; failures distinguish
  missing locations, timeouts, rate limits and provider errors.
- **Twitch recovery:** Shared supervision detects stalled protocol or subscription
  recovery, safely retires the old client and retries with bounded backoff while
  preserving the selected operating mode and running intent. The dashboard shows
  recovery progress. Connection readiness now requires the configured subscription
  and send readiness, with stronger ownership and cleanup across reconnects and Stop.

## Known Uncertainty

The historical intermittent missed-message/reconnect incident is not conclusively
resolved. These changes correct demonstrated failure paths, but their presence and
short acceptance checks do not establish the original cause or long-term stability.
Messages missed during a disconnection are not replayed.

## Updating

Back up the whole profile before updating. Exit Windows Desktop fully through
**tray Exit** before installing or replacing portable files. Keep the existing
profile and credentials; this update adds no database schema migration over v1.5.1.
Older profiles must follow the
[upgrade and recovery guide](https://github.com/heeetz/heetkit-bot/blob/v1.5.2/docs/data-and-privacy.md#versioned-database-upgrade-and-recovery).
Independent backups need their own expiry, deletion and opt-out handling.

For Server, follow the
[release update procedure](https://github.com/heeetz/heetkit-bot/blob/v1.5.2/docs/docker.md#repeatable-release-update).
Preserve the existing profile volume, external secrets, architecture and operating
policy. Run one instance per Twitch bot account; updates do not renew OAuth consent.

Windows downloads remain unsigned and retain the existing .NET Framework and WebView2
requirements. Automated validation does not establish installed Windows acceptance
or resolve the recorded
[redistribution questions](https://github.com/heeetz/heetkit-bot/blob/v1.5.2/THIRD_PARTY_NOTICES.md#next-windows-build-corrected-materials-and-remaining-blockers).
