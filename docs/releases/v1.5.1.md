# HeetKit v1.5.1

This release adds private local analytics, channel-scoped conversation history and
more control over command access, with shared improvements for Desktop and Server.

## What's New

- **Private Analytics:** View command outcomes, AI usage and estimated spending,
  observed chat activity and retained-user counts. Today shows UTC hourly activity;
  longer ranges use daily totals. Collection can be disabled and its history reset.
  Existing daily history is preserved without inventing past hourly observations.
- **Channel-scoped history and privacy:** Presence and personal AI history stay
  separate for each channel, with bounded retention and configurable AI memory
  limits. Viewers can use `!optout` to stop local identifying storage and remove
  their stored presence and AI history across the profile's channels.
- **Command access and naming:** Manage per-user command restrictions with optional
  expiry, rename built-in chat triggers, and keep public help aligned with enabled
  commands. AI restrictions and opt-out management share the existing controls.

## Improvements & Fixes

- Refined Analytics, AI state, command and navigation layouts, including narrow
  screens, clearer memory controls and on-demand provider balance checks.
- Added a Desktop startup form for explicitly assigning legacy history to a channel.
  Startup errors remain visible and an unfinished choice is not silently saved.
- Improved Twitch connection ownership, reconnect cleanup and sanitized diagnostics.
  These changes do not establish that the intermittent message issue below is fixed.

## Known Issue

We are aware that HeetKit can occasionally miss some messages unexpectedly. We are
still investigating and working on a fix; this release does not resolve that issue.

## Updating

Back up the whole profile before updating. Exit Windows Desktop fully through
**tray Exit** before installing or replacing portable files.

Older profiles may require an explicit channel assignment for legacy history.
Database upgrades preserve supported data but change its storage schema; do not
open an upgraded profile with an older release. Follow the
[upgrade and recovery guide](https://github.com/heeetz/heetkit-bot/blob/v1.5.1/docs/data-and-privacy.md#versioned-database-upgrade-and-recovery)
for recovery snapshots, expiry and privacy handling. Independent backups need
their own deletion and opt-out handling.

For Server, follow the
[release update procedure](https://github.com/heeetz/heetkit-bot/blob/v1.5.1/docs/docker.md#repeatable-release-update).
Keep the existing profile volume, external secrets, architecture and operating
policy. Run one instance per Twitch bot account; updates do not renew OAuth consent.

Windows downloads remain unsigned and keep the existing .NET Framework and WebView2
requirements. Recorded
[redistribution questions](https://github.com/heeetz/heetkit-bot/blob/v1.5.1/THIRD_PARTY_NOTICES.md#next-windows-build-corrected-materials-and-remaining-blockers)
and installed-artifact manual acceptance remain separate from automated checks.
