# HeetKit v1.5.5

Desktop and Server now show built-in commands, custom commands and chat reactions
in one **Commands** list. Search and filter the list, or use **Create** to add a
custom command or chat reaction. New entries appear first by default.

## Improvements and fixes

- **Command editing** groups reply text, access, aliases and conditions into
  sections. Enable or disable entries from the list and reorder reaction matching
  priority in the editor.
- **Chat privacy** handles repeated storage opt-out requests without sending
  repeated confirmations and lets viewers retry when recovery cleanup fails.
- **Twitch setup and Server access** check the authorized bot account and required
  permissions on Desktop before saving the token. On Server, rejected traffic
  no longer shares the rate limit for authenticated requests or valid Twitch
  authorization returns.
- **DeepSeek search** checks destinations before fetching pages and blocks
  private or local addresses.

## Updating

Installed copies of v1.5.4 can use **About > Update & restart** once v1.5.5 is
available. For a manual install, back up your profile and exit HeetKit from the
tray before running Setup. Portable copies update by downloading the new ZIP.
