# HeetKit v1.5.4

Windows Desktop checks for a newer stable release after startup. When one is
available, **Update available** beside **Start Bot** or **Stop Bot** opens the
update section in **About**. You can still check there on demand.

## Improvements and fixes

- **Verified Windows updates:** Installed copies can download and verify a
  future signed installer from **About > Update & restart**. HeetKit backs up
  the stopped profile, applies the installer and reopens automatically.
- **Twitch setup:** Desktop offers **Save & restart** when changed credentials
  or bot identity require a restart. Channel changes can reconnect without
  restarting the app.
- **AI search:** DeepSeek and OpenAI can search when enabled for the selected
  connection. OpenAI answers preserve inline source citations.

## Updating

Install v1.5.4 manually to add the publisher key used for future updates.
Back up your profile and exit HeetKit from the tray before running Setup.
Portable copies continue to update by download.

The detached Ed25519 signature verifies the installer through HeetKit's updater.
Windows may identify Setup as an unknown publisher.
