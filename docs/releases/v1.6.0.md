# HeetKit v1.6.0

HeetKit now speaks Ukrainian and Russian. Choose the interface language in
**Settings > Interface language** or from the language menu beside **About**.
On Windows, Setup asks for the language too and HeetKit starts in it. Bot replies
in Twitch chat keep their own language settings.

## Improvements and fixes

- **Dashboard and Settings** have a refreshed layout. The bot account, channel and
  Twitch application are grouped in the order you fill them in, and the setup guide
  follows the same order.
- **Descriptions and help** are shorter. Longer explanations moved into labelled
  help popovers.
- **Chat message counting** can be paused in Analytics without turning off analytics
  collection.
- **Logs** record why a chat command produced no reply.

## Updating

Installed copies of v1.5.6 can use **About > Update & restart** once v1.6.0 is
available. For a manual install, back up your profile and exit HeetKit from the
tray before running Setup. Portable copies update by downloading the new ZIP.

HeetKit keeps your saved interface language. A first start without one uses the
language chosen in Setup, otherwise English.
