# HeetKit v1.3.0

This release adds local privacy controls and automatic data retention, with a more
compact interface, clearer setup and AI editing, and improved reliability.

## What's New

- **Automatic Data Retention:** Successful AI exchanges are retained for up to
  **90 days**, while only the **5 most recent exchanges per viewer** are sent to
  Gemini as conversation context. Viewer records expire after **180 days of
  inactivity**.
- **Manual Privacy Requests:** Operator tooling can delete a viewer's local records
  or apply a persistent storage opt-out. Opt-outs prevent future viewer/history
  storage and suppress related application chat diagnostics, without adding new
  chat commands.

## Improvements & Fixes

- Redesigned Dashboard and AI overview with compact status panels, clearer
  connection states, and easier access to conversation memory and Gemini controls.
- Unified styling, keyboard-accessible accordion headers, and question-mark help
  across Commands, Filters, AI, and Settings. Improved tooltip placement and dismissal.
- Improved responsive layouts, sidebar scrolling, editor footers, and update controls
  so fields and actions fit smaller windows more cleanly.
- `!ask` enablement now persists across restarts and stays synchronized across
  Dashboard, AI, and Commands without saving unrelated command drafts.
- Clearer Twitch setup separates required configuration, authorization, and optional
  Gemini setup, with explicit restart feedback after identity or secret changes.
- Clearer AI save boundaries, language and model controls, personality editing, and
  draft choices before opening Playground. Simplified command editing and built-in
  recovery, with clearer filter feedback and navigation labels.
- AI blocking now reports timeouts and cancellation. Reaction files accept UTF-8
  with or without a BOM, with clearer loading errors that preserve existing files.
- AI replies that Twitch does not deliver are no longer recorded as successful
  conversation history.
- Updated setup, command, and privacy guides, expanded regression coverage, and
  streamlined Windows CI dependency downloads and browser setup.

## Updating

Exit HeetKit completely through **tray Exit** before installing the new version.
Existing profiles, credentials, and settings are preserved. The new retention policy
automatically removes expired AI history and inactive viewer records, including when
conversation memory is off. Manual privacy requests are handled by the bot operator;
`!erase` remains limited to AI memory.
