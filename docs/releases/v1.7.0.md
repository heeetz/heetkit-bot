# HeetKit v1.7.0

Add as many AI providers as you need, including your own OpenAI-compatible server
such as LM Studio, and control the bot from a reworked Dashboard.

## New

- **Any number of AI providers.** Add Google, DeepSeek, OpenAI or a custom
  OpenAI-compatible server, several of one kind if you like, each with its own
  name and key. On Server, a custom provider uses public HTTPS addresses unless
  private networks are allowed.
- **Dashboard quick controls.** Start and stop the bot from the Dashboard. A manual
  stop is saved and survives restarts. Switch the personality and main model, or
  ignore a viewer, without leaving the page.
- **Reply interval.** Set the pause between bot messages (0–60 s) in Settings.
- **Server sign-in** survives a page reload. **Remember me** keeps a device signed in
  for 30 days, and **Sign out on all devices** ends every session.
  `scripts/heetkit-token.sh` shows or resets the management token on the host.
- **Command variable hints** are back in the command editor.

## Improvements and fixes

- **Safer chat input.** Filters also catch look-alike letters, invisible characters
  and spaced-out words. Custom command replies are checked against the filters too,
  and AI answers with links outside their search sources are withheld.
- **Faster** Server panel and chat filtering.
- **Commands list** switches to cards before columns get too narrow, so text no
  longer wraps letter by letter at mid window widths.
- **Phones with a notch or camera island** keep the Server panel, dialogs and
  notifications clear of it.
- **Help tips** are shorter and use bullet points.
- AI provider balance and cost display was removed. `!tg` is now a Burst custom
  command you can edit.

## Updating

Installed copies of v1.6.0 can use **About > Update & restart** once v1.7.0 is
available. For a manual install, back up your profile and exit HeetKit from the
tray before running Setup. Portable copies update by downloading the new ZIP.

The first start moves profile settings into one `config/config.json` and keeps the
old files in `config/backup-1.6/`. After that, v1.6.0 cannot read the profile: to go
back, restore the pre-update snapshot described in the update recovery guide.
AI provider keys and models carry over.
