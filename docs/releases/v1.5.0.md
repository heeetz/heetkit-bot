# HeetKit v1.5.0

This stable release brings OpenAI, DeepSeek and Gemini into one shared AI setup,
adds scheduled Twitch announcements, and expands the authenticated Server panel.
It includes the changes tested in v1.4.2 and v1.4.3-beta.1 since stable v1.4.1.

## What's New

- **OpenAI support:** Use the Responses API with a separately stored key, saved
  connections, native reasoning controls and optional bounded Web Search. Choose
  a primary model and an optional fallback with independent provider settings.
- **DeepSeek support:** Configure direct DeepSeek models, thinking and supported
  Search/Fetch tools alongside Gemini. Cross-provider fallback requires an explicit
  acknowledgement before questions and permitted context can reach another provider.
- **Shared AI instructions and Playground:** Edit profile-wide instructions and
  question/answer limits. Desktop and authenticated Server share the same AI
  pipeline, privacy rules, filtering, language policy and operator Playground.
- **Scheduled announcements:** Save interval-based schedules with activity and
  stream conditions. Choose highlighted Twitch announcements or regular chat
  messages, edit schedules, and immediately enable or disable saved entries.
- **Operator activity:** Follow command attempts, AI work and outgoing replies
  through linked events, including failed and uncertain sends.
- **Larger response pools:** Custom commands support up to 30 random responses.

## Improvements & Fixes

- Refined AI setup, Twitch Settings, announcement editors and narrow-screen layouts.
- Shared output limits and connection lifecycle protect regular and highlighted
  sends. Failed highlighted messages never silently become regular chat messages.
- Release deployment now makes archived public source readable by the non-root
  container user under a private umask. Failed candidate state and startup logs are
  retained privately before rollback replaces the container.
- Release builds bind validation, Windows artifacts, checksums and publication to
  one exact source commit. Server updates retain stopped-profile backups and the
  previous image for compatible rollback.

## Updating

Back up the profile first. Exit Windows Desktop fully through **tray Exit** before
installing or replacing portable files. Existing profiles and credentials remain
supported. Add new provider keys separately; configuration transfer excludes secrets
and requires renewed cross-provider fallback acknowledgement on the destination.

Existing announcement schedules keep regular delivery until explicitly changed.
Highlighted announcements require the appropriate Twitch authorization and a
moderator or broadcaster sending account. This update does not renew OAuth consent.

For Server, follow the [release update procedure](https://github.com/heeetz/heetkit-bot/blob/v1.5.0/docs/docker.md#repeatable-release-update).
Keep the Compose project, profile volume, external secrets and architecture. Run one
instance per Twitch bot account. Updates remain an explicit operator action.

Windows downloads remain unsigned and keep their existing .NET Framework and
WebView2 requirements. The recorded [redistribution requirements](https://github.com/heeetz/heetkit-bot/blob/v1.5.0/THIRD_PARTY_NOTICES.md#next-windows-build-corrected-materials-and-remaining-blockers)
and artifact-specific manual acceptance remain separate from automated validation.
