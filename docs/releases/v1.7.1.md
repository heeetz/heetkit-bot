# HeetKit v1.7.1

A fix for the commands list in the default Desktop window.

## Fixes

- **Commands list** shows its full table again in the default 1180 px Desktop
  window. v1.7.0 switched to cards there. In narrower windows the table stays and
  **Edit** and **Delete** stack in the row, so names and responses keep their room.
  Only very narrow windows and phones use cards, with the switch on the left.
- Command list column headings are centered.

## Updating

Installed copies of v1.6.0 or v1.7.0 can use **About > Update & restart**. Portable
copies update by downloading the new ZIP. Updating from v1.6.0 moves profile settings
into one `config/config.json`, as described in the v1.7.0 notes. After that, v1.6.0
cannot read the profile.
