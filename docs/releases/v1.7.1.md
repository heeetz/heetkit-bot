# HeetKit v1.7.1

A hotfix for the Commands list in v1.7.0.

## Fixes

- **Commands list** shows the full table again in the default Desktop window,
  with the switch, name, reply, access and buttons on one line. In narrower
  windows the table stays and **Edit** moves above **Delete**; only narrow
  screens and phones switch to cards, with the switch on the left.
- **Commands list** column headings are centered.

## Updating

Installed copies of v1.7.0 or v1.6.0 can use **About > Update & restart** once
v1.7.1 is available. For a manual install, back up your profile and exit HeetKit
from the tray before running Setup. Portable copies update by downloading the new ZIP.

Updating from v1.6.0 moves profile settings into one `config/config.json` as
described in the v1.7.0 notes; after that, v1.6.0 cannot read the profile.
